# Story 15.8 — Escolha de Hidratação ao Selecionar Template

**Epic:** EP-15 — Templates e Editor Visual
**Status:** Ready for Dev
**Priority:** Medium

---

## User Story

**Como** usuário que está selecionando um template,
**Quero** escolher se quero usar meu template preenchido com os dados do meu perfil ou em branco,
**Para** ter controle sobre o ponto de partida da minha landing page.

---

## Contexto

A `TemplatesPage` já implementa a função `hydrarTemplateComPerfil()` automaticamente quando o perfil existe, mas o usuário não sabe que isso acontece nem tem opção de escolha.

**Arquivo principal:** `src/app/routes/TemplatesPage.tsx`
**Função de hidratação:** `src/features/editor/utils/hydrate-template.ts` → `hydrarTemplateComPerfil(json, perfil, socios)`

---

## Acceptance Criteria

### AC1 — Modal de escolha ao clicar "Usar"
- Ao clicar no botão "Usar" de qualquer template, abrir um modal de escolha (não navegar diretamente)
- Modal exibe o nome do template selecionado
- Duas opções:
  - **"Com meus dados"** — aplica `hydrarTemplateComPerfil()` e abre no editor
  - **"Em branco"** — abre o template sem hidratação

### AC2 — Perfil completo disponível
- Quando `perfil !== null` e `perfil.onboarding_completo === true`:
  - Botão "Com meus dados" está **habilitado** e é a opção destacada (primary)
  - Botão "Em branco" está habilitado como opção secundária

### AC3 — Perfil incompleto ou ausente
- Quando `perfil === null` ou `perfil.onboarding_completo === false`:
  - Mostrar aviso: `"Seu perfil está incompleto. Complete o onboarding para preencher automaticamente."`
  - Link/botão "Completar perfil" que navega para `/onboarding`
  - Botão "Em branco" continua disponível e habilitado
  - Botão "Com meus dados" está **desabilitado** (com tooltip explicando)

### AC4 — Modal acessível via Preview também
- O botão "Usar Template" dentro do modal de Preview deve disparar o mesmo modal de escolha

### AC5 — UX do modal
- Modal com fundo overlay escuro
- Título: `"Como deseja começar?"`
- Subtítulo: nome do template selecionado
- Botão fechar (X) ou clicar fora para cancelar
- Não bloquear scroll da página
