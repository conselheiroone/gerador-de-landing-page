## Story

**As an** admin,
**I want** poder abrir um template já importado diretamente no editor visual a partir da listagem de templates,
**so that** eu possa ajustar o layout importado sem precisar re-importar a URL do zero.

## Acceptance Criteria

1. Na listagem de templates do admin (`/admin/templates`), templates com `categoria = 'Importado'` exibem um botão/ação **"Editar no Editor"**
2. Ao clicar em "Editar no Editor", o admin é redirecionado para `/editor/{id}` com o Craft.js JSON carregado a partir do campo `dados_template` do template
3. O editor abre com o template pré-carregado e totalmente editável (todas as props disponíveis, sem restrição de `editavel_cliente`)
4. Ao salvar dentro do editor, o campo `dados_template` do template existente é **atualizado** (não cria um novo template)
5. O fluxo funciona tanto para templates importados via Playwright quanto via Edge Function

### Fluxo de dados atual (referência)

```
AdminImportarLayoutPage
  └─→ criarTemplate(nome, desc, cat, craftJson, userId)  → INSERT em templates
  └─→ navigate('/editor/novo', { state: { templateJson } })  → EditorPage sem persistência automática
```

### Fluxo esperado após esta story

```
AdminTemplatesPage (listagem)
  └─→ botão "Editar no Editor" em card de template
      └─→ navigate('/editor/:id')

EditorPage (modo edição de template)
  └─→ detecta params.id → busca templates onde id = params.id
  └─→ deserialize craftJson → editor carregado
  └─→ save → UPDATE templates SET dados_template = ? WHERE id = params.id
```

### Tabela `templates` (Supabase)

Colunas relevantes:
- `id` UUID — chave primária
- `dados_template` JSONB — o Craft.js JSON serializado
- `categoria` TEXT — valor `'Importado'` para templates importados
- `ativo` BOOLEAN

### Convenções do projeto

- Usar `useEditorSave` para lógica de persistência
- Validação com Zod nas Edge Functions se houver endpoint dedicado
- RLS: admin tem full access na tabela `templates`
- Navegação via `react-router-dom` v7 (`useParams`, `useNavigate`, `useLocation`)

### Testing

- Testes manuais no fluxo completo (import → edit → save)
- Verificar no Supabase Studio que `dados_template` foi atualizado (não duplicado)
- Checar que a galeria do cliente reflete as mudanças após save
